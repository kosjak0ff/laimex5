# Laimex — лотереи в магазинах Латвии

Сайт: **https://kosjak0ff.github.io/laimex5/**

Сайт сам находит все действующие товарные лотереи Латвии и показывает для каждой:
- что купить;
- где покупать;
- как и до какого числа зарегистрировать чек;
- когда розыгрыши;
- какие призы и общий призовой фонд;
- номер разрешения и организатора;
- где смотреть победителей прошедших розыгрышей.

Журнальные и газетные лотереи не показываются. Сайт ставится на телефон как приложение.

## Как это работает

Работают два помощника.

**Робот на GitHub Actions** (файл `.github/workflows/daily.yml`):
1. Скачивает **реестр разрешений VID** (Excel-файл со страницы vid.gov.lv/lv/loterijas). Это
   официальный список всех лотерей: номер, организатор, что купить, даты.
2. Ищет страницы и **правила** лотерей на сайтах агентств loterijas.lv и loterijatev.lv и на
   страницах кампаний.
3. Скачивает правила (PDF или веб-страницу) и извлекает текст.
4. Готовит для Claude задания на выжимку (`data/pending/`). Задание появляется только для новых
   лотерей и для правил, которые изменились.
5. Собирает сайт в папку `docs/` и публикует его в ветку `gh-pages`, откуда его показывает
   GitHub Pages. Изменения от Claude публикует `.github/workflows/publish.yml`.
6. **Проверяет здоровье системы.** Если реестр не обновлялся, задача Claude давно ничего не
   сохраняла или лотерея больше двух дней ждёт выжимку, робот открывает на GitHub issue
   «Laimex: нужна проверка», и GitHub присылает письмо. Когда всё наладится, issue закроется само.

Робот запускается по расписанию (02:37 UTC; GitHub часто опаздывает на несколько часов) и,
главное, по команде задачи Claude.

**Задача Claude** «Laimex: выжимки лотерей» (06:07 по Риге, инструкция в `ROUTINE.md`):
1. Сначала сама запускает робота (`tools/run_robot.py`) и ждёт свежих данных.
2. **Делает выжимки** из правил по строгому шаблону (`laimex/schema.py`).
3. **Автоматически проверяет** каждую выжимку:
   - даты и номер разрешения сверяются с реестром VID;
   - сумма призов должна сойтись с призовым фондом;
   - число призов в розыгрышах должно совпасть с числом призов в фонде.

   Если что-то не сходится, на сайте появляется пометка «Проверьте по правилам».
4. Ищет через веб-поиск правила лотерей, которых нет у агентств, снова запускает робота, чтобы
   он их скачал, и делает выжимки в тот же день. Ищет только для уже идущих лотерей: у будущих
   информации обычно ещё нет.
5. Для идущих и недавно закончившихся лотерей, у которых прошёл розыгрыш, ищет страницу с
   победителями и записывает ссылку в `data/results.json`. Сайт показывает её в карточке.

Если однажды задача Claude не отработает, робот по расписанию всё равно обновит список лотерей
из реестра. Если упадёт сам робот, GitHub пришлёт письмо на почту владельца репозитория.

Лотерея появляется на сайте сразу, как только попала в реестр. Пока правила не разобраны,
в карточке показаны данные из реестра. Счётчики «ещё N дней» (до конца регистрации чеков) и «ближайший розыгрыш»
пересчитываются прямо в телефоне, так что они верны, даже если обновление однажды пропустится.

## Папки

| Папка | Что в ней |
|---|---|
| `laimex/` | программа робота |
| `web/` | исходники сайта: страница, стили, установка на телефон, иконки |
| `docs/` | готовый сайт (публикуется) |
| `data/registry.json` | актуальные лотереи из реестра VID |
| `data/sources.json` | найденные ссылки на страницы, правила и регистрацию |
| `data/summaries/` | выжимки по каждой лотерее |
| `data/results.json` | ссылки на победителей розыгрышей и дата последнего поиска |
| `data/pending/`, `data/todo.json` | задания для Claude |
| `data/rules_text/` | текст правил (по нему видно, когда правила меняются) |
| `data/manual_rules/` | текст правил, которые робот скачать не может (например, с Google Диска); подключается полем `rules_local` в `data/sources.json` |
| `ROUTINE.md` | единственная инструкция для ежедневной задачи Claude |
| `tools/` | запуск робота из задачи Claude, проверка коммита рутины, публикация сайта |

## Запуск

Основной вариант: робот GitHub Actions плюс **рутина Claude по подписке** (см. `ROUTINE.md`).

Без рутины, только через **Claude API**:
- в настройках репозитория (Settings → Secrets and variables → Actions) создайте переменную
  `LAIMEX_MODE=api` и секрет `ANTHROPIC_API_KEY`;
- тогда робот делает выжимки сам;
- это стоит порядка $1–2 в месяц.

Команды для ручного запуска:

```bash
pip install -r requirements.txt
python -m laimex daily --mode agent   # реестр, правила, задания, сайт
python -m laimex todo                 # что осталось сделать
python -m laimex save 9158 file.json  # сохранить выжимку и увидеть проверки
python -m laimex add-result 9158 --winners URL --note "..."  # победители розыгрышей
python -m laimex build                # пересобрать сайт
pip install -r requirements-dev.txt   # для тестов
python -m pytest -q                   # тесты (на GitHub их запускает laimex-tests)
```

## Правила вежливости робота

Робот:
- соблюдает robots.txt;
- делает паузу не меньше секунды между запросами к одному сайту;
- скачивает только публичные страницы;
- никогда не заполняет формы.
